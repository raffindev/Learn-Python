## Comandos - Git

```bash
git init     # inicia a linha do tempo
git add      # adiciona ou atualiza mudanças
git commit   # adiciona um ponto na linha do tempo
git log      # visualiza os commits
git status   # informa o estado das alterações
git show     # apresenta determinado ponto na história
git branch   # gerencia novas linhas do tempo
git checkout # manipula as linhas do tempo
git merge    # une linhas do tempo
git push     # envia alterações para o repositório remoto
git clone    # clona um projeto/repositório
git pull     # puxa alterações do repositório remoto
